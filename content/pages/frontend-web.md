- El frontend web es la interfaz que el usuario ve y opera en el navegador; la Wikipedia en español relaciona HTML, CSS y JavaScript con el desarrollo del lado cliente https://es.wikipedia.org/wiki/Desarrollo_web
- MDN Learn enseña estructura HTML, estilo CSS y comportamiento con JavaScript para páginas y aplicaciones en el navegador https://developer.mozilla.org/es/docs/Learn_web_development
- El libro Eloquent JavaScript (4.ª ed., 2024) de Haverbeke es de acceso libre y recorre el lenguaje, el DOM y cómo el navegador habla con el servidor https://eloquentjavascript.net/
- MDN explica componentes de una app web moderna: documento, estilo, scripts y peticiones HTTP al backend https://developer.mozilla.org/es/docs/Learn_web_development/Getting_started/Your_first_website
- El frontend no se agota en aprender un framework: el Frameworkless Movement plantea que adoptar uno es una decisión técnica con deuda y alternativas, y que entender la plataforma es lo que habilita elegir bien https://www.frameworklessmovement.org/
- Frameworkless.js lleva esa idea a la práctica y construye una aplicación completa con Node y JavaScript de a pie: servidor HTTP, ruteo, plantillas, SQL sin ORM y reactividad sin framework https://frameworkless.js.org/
- Este curso en video de freeCodeCamp construye interfaces con HTML, CSS y JavaScript desde cero hasta un sitio usable https://www.youtube.com/watch?v=nu_pCVPKzTk
