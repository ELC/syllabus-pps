- La programación funcional trata el cálculo como evaluación de funciones puras; la Wikipedia en español destaca inmutabilidad, recursión y funciones de alto orden [@paradigma-funcional]
- El desarrollo guiado por tipos usa anotaciones y contratos para detectar errores antes de ejecutar; la documentación de typing de Python formaliza hints y narrowing [@typed-driven-python]
- ts-pattern muestra pattern matching exhaustivo sobre uniones de tipos como alternativa legible a cadenas de if [@ts-pattern-library]
- Real Python (2024) muestra funciones de primer orden, `map`, `filter`, `reduce` e inmutabilidad práctica en Python [@python-functional-programming]
- El libro Automate the Boring Stuff with Python (2.ª ed., 2019) de Sweigart introduce funciones reutilizables y composición antes de estructuras más avanzadas [@automate-the-boring-stuff-with-python]
- MIT 6.006 (2020) contrasta paradigmas y analiza recursión, divide and conquer y abstracciones funcionales [@mit-6-006-2020]
- La especialización Algorithms de Tim Roughgarden en Coursera usa divide and conquer y programación dinámica con estilo declarativo [@algorithms-specialization]
