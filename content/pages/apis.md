- Una API es el contrato por el que un sistema ofrece operaciones a otros programas; la Wikipedia en español distingue APIs locales, web y de biblioteca [@api]
- Martin Fowler recorre el modelo de madurez de Richardson con pedidos HTTP de ejemplo que pasan de un endpoint único a recursos, verbos y controles de hipermedia [@richardson-maturity-model-fowler]
- La Wikipedia en inglés resume los cuatro niveles del modelo de madurez de Richardson y su relación con REST y HATEOAS [@richardson-maturity-model]
- El libro gratuito Web API Design: The Missing Link (Apigee, 2016) discute diseño de URLs, versionado y manejo de errores en APIs web [@web-api-design-the-missing-link]
- Este video de ByteByteGo resume APIs REST, recursos y el rol del contrato frente a un frontend o a otro servicio [@what-is-rest-api-examples-and-how-to-use-it-cras]
