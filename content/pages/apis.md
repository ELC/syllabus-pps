- Una API es el contrato por el que un sistema ofrece operaciones a otros programas; la Wikipedia en español distingue APIs locales, web y de biblioteca https://es.wikipedia.org/wiki/API
- Martin Fowler recorre el modelo de madurez de Richardson con pedidos HTTP de ejemplo que pasan de un endpoint único a recursos, verbos y controles de hipermedia https://martinfowler.com/articles/richardsonMaturityModel.html
- La Wikipedia en inglés resume los cuatro niveles del modelo de madurez de Richardson y su relación con REST y HATEOAS https://en.wikipedia.org/wiki/Richardson_Maturity_Model
- El libro gratuito Web API Design: The Missing Link (Apigee, 2016) discute diseño de URLs, versionado y manejo de errores en APIs web https://docs.apigee.com/files/Web-design-the-missing-link-ebook-2016-11.pdf
- Este video de ByteByteGo resume APIs REST, recursos y el rol del contrato frente a un frontend o a otro servicio https://www.youtube.com/watch?v=-mN3VyJuCjM
