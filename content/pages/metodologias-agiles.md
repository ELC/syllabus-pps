- El desarrollo ágil entrega software en ciclos cortos con inspección y adaptación; la Wikipedia en español contrasta enfoques iterativos con el modelo en cascada [@desarrollo-agil-de-software]
- La Scrum Guide (2020) define roles, eventos y artefactos de Scrum como marco liviano para generar valor de forma empírica [@scrum-guide]
- El libro Shape Up (2019) de Ryan Singer es de acceso libre y muestra ciclos acotados, apetito y entrega de trabajo que importa [@shape-up]
- Este curso de Coursera dictado por John Rofrano aplica Scrum con user stories, story points, refinamiento de backlog y burndown charts en labs sobre GitHub [@agile-development-and-scrum]
- Este curso de Coursera armado por Scrum Alliance recorre valores y prácticas ágiles, cómo cambian los roles del equipo y casos fuera del software [@agile-essentials]
