- El desarrollo ágil entrega software en ciclos cortos con inspección y adaptación; la Wikipedia en español contrasta enfoques iterativos con el modelo en cascada https://es.wikipedia.org/wiki/Desarrollo_%C3%A1gil_de_software
- La Scrum Guide (2020) define roles, eventos y artefactos de Scrum como marco liviano para generar valor de forma empírica https://scrumguides.org/scrum-guide.html
- El libro Shape Up (2019) de Ryan Singer es de acceso libre y muestra ciclos acotados, apetito y entrega de trabajo que importa https://basecamp.com/shapeup
- Este curso de Coursera dictado por John Rofrano aplica Scrum con user stories, story points, refinamiento de backlog y burndown charts en labs sobre GitHub https://www.coursera.org/learn/agile-development-and-scrum
- Este curso de Coursera armado por Scrum Alliance recorre valores y prácticas ágiles, cómo cambian los roles del equipo y casos fuera del software https://www.coursera.org/learn/agile-essentials
- Este video compara waterfall, agile e híbridos para ubicar Scrum y Kanban en la gestión de un proyecto de software https://www.youtube.com/watch?v=bLZ9MNwV2vE
