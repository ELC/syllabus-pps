- Un agente autónomo percibe, decide y actúa para alcanzar objetivos; la Wikipedia en español describe arquitecturas clásicas y bucles percepción-acción [@agente-inteligente]
- El curso NLP de Hugging Face conecta generación de texto con bucles que llaman herramientas externas [@huggingface-llm-course]
- Prompt Engineering Guide (2024) cubre agentes, planificación y uso de APIs desde modelos de lenguaje [@prompt-engineering-guide]
- Este video de IBM Technology muestra cómo un LLM elige herramientas y ejecuta pasos en cadena [@llm-agents-explained]
- El Model Context Protocol de Anthropic (2024) estandariza cómo un agente accede a contexto y servicios externos [@model-context-protocol]
- El protocolo Agent2Agent (A2A) de Google define mensajes entre agentes heterogéneos en flujos multiagente [@agent-to-agent-protocol]
- AG-UI estandariza eventos entre agentes y aplicaciones web mediante streaming [@ag-ui-protocol]
- A2UI define componentes declarativos que un agente puede renderizar en el cliente [@a2ui-protocol]
- El libro Software Engineering at Google (1.ª ed., 2020) documenta pruebas, revisión y operación de sistemas con componentes autónomos [@software-engineering-at-google]
