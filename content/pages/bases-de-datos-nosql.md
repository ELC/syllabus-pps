- Las bases NoSQL priorizan modelos documentales, clave-valor o grafos según el caso; la Wikipedia en español compara familias y trade-offs frente al relacional [@nosql]
- Redis es el almacén clave-valor más usado para caché, sesiones y colas ligeras en sistemas de alta demanda [@redis-documentation]
- PostgreSQL incorpora JSON/JSONB y colas nativas, mostrando convergencia entre SQL y capacidades NoSQL [@postgres-jsonb]
- El teorema CAP limita consistencia, disponibilidad y tolerancia a particiones en sistemas distribuidos; la Wikipedia en español lo enuncia con ejemplos [@teorema-cap]
- El libro Designing Data-Intensive Applications (1.ª ed., 2017) de Kleppmann profundiza modelos de datos, replicación y particionado [@designing-data-intensive-applications]
- Database System Concepts (7.ª ed., 2020) de Silberschatz, Korth y Sudarshan contrasta SQL con almacenes especializados y consultas [@database-system-concepts]
- Este curso de freeCodeCamp introduce almacenes NoSQL dentro de pipelines modernos de datos [@data-engineering-fundamentals]
